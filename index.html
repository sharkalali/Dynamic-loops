Dynamic Loops

How loops adapt their steps, conditions, and output at runtime

1. What Does "Dynamic Loop" Mean?

A dynamic loop does not use fixed numbers written in advance. Instead, it decides how many times to run, how big each jump (step) is, or which items to keep while the program is actually running.

Static Loop

Fixed limit (e.g. always 1 to 10). Same behavior every single time you run it.

Dynamic Loop

Reads live values (start, end, step, filter, or list length) and builds the result on the fly.

for (let i = start; i <= endLimit; i += step) {
  if (matchesCondition(i)) createBox(i);
}
